# YouTube で登録チャンネルの動画だけ見たい。おすすめやショートを消す方法は？

YouTube アプリは［ホーム］タブで開き、［登録チャンネル］はホームの上部バーで毎回タップするフィードで、そこから開くようにする設定は YouTube ヘルプに見つかりません。minulo の中で YouTube を開き、歯車で［登録チャンネルだけにする］を選ぶと、登録チャンネルから開いて、ホームのおすすめとショートが消えます（消すのは無料、Pro は有料）。

## 手順
1. YouTube アプリだけで見るなら：アプリを開き、ホームの上部バーで［登録チャンネル］をタップします。登録したチャンネルの最新動画が並びます。
2. ホームを少し絞るなら：動画の横の ⋮ から［興味がない］や［チャンネルをおすすめに表示しない］を、ショートのグリッドの上のその他アイコンから［ショート動画の表示を減らす］を選びます。どれも減るだけで、おすすめは続きます。
3. 再生履歴を止めるとホームのおすすめが消えることがあります。ただ YouTube ヘルプ（英語）によると、そのあいだは［登録チャンネル］を含む上部のバーも出なくなります。
4. minulo を入れて、minulo の中で YouTube を開きます。
5. YouTube の横の歯車で［登録チャンネルだけにする］を選びます。検索も使いたいなら［ショートとおすすめを非表示］を選びます。再生履歴はオンのままで大丈夫です。

## ほかの選択肢
- **Unhook**：パソコンの Chrome・Firefox・Edge に入れる拡張機能で、おすすめやショートを消せます。効くのはブラウザの中だけで、iPhone の YouTube アプリは変わりません。
- **Safari の機能拡張**：Safari の youtube.com でショートを隠せますが、効くのは Safari の中だけです。
- **YouTube の［ショート動画の表示を減らす］**：公式の機能です。ショートは減りますが、なくなりません。

## よくある質問
### ［登録チャンネルだけにする］と［ショートとおすすめを非表示］はどう違いますか？
［登録チャンネルだけにする］は、ショートとホームのおすすめに加えて、検索、コメント、チャンネルの投稿も消えます。調べ物で YouTube を検索するなら［ショートとおすすめを非表示］が合います。こちらでもホームのおすすめとショートは消えます。

### minulo は公式の YouTube アプリを変えますか？
変えません。minulo は自分のアプリの中で YouTube のウェブ版を表示します。公式アプリをスクリーンタイムで止めることもでき（1回2時間まで無料）、iPhone では止めているあいだは登録チャンネルの新着の通知も届かず、minulo が代わりに届けることもありません。Android では、止めたアプリを開いたときに minulo の画面が上に出るだけなので、通知は届きます。minulo は iPhone と Android で使え、Mac 版もあります。
