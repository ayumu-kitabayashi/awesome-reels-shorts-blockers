# SocialLite は無料？

SocialLite は無料でダウンロードでき、アプリ内課金がありますが、App Store の説明にはどの機能が無料かは書かれていません。minulo は、何も買わずにリール・ショート・おすすめ投稿を消せる iPhone アプリです（隠すのは無料、Pro は有料）。

## 公式の設定でできること
料金の問いなので、SocialLite の米国の App Store の表示を書きます（2026-10-26 確認）。
- Pro は表示されるプランによって月6.99〜17.99ドル、年19.99〜47.90ドルです。
- ファミリープランは月12.99ドルです。
- App Store のページにはいくつものプランが出るので、見える料金が人によって違うことがあります。

## できるアプリ
- **minulo**：10の SNS でリール・ショート・おすすめ投稿を消すこと、［DM以外のタブ］、公式アプリを1回2時間まで止めることが無料です。Pro（日本は月1,480円・年6,800円・買い切り23,800円）でスリープモード（毎日同じ就寝・起床時刻）・ハードモード・1日の上限・2時間を超えるブロックが使えます。最初の7日間はだれでも Pro のすべてを無料で使えます。
- **Nope**：すべて無料で、サブスクもアプリ内課金もありません。Safari の instagram.com と youtube.com だけです。
- **noShorts**：アプリの中で使え、すべて無料です。2026年10月に出たばかりです。
- **Stillfeed**：7つの SNS でリールとショートを消すのは無料で、ストーリーズやフィードを隠す機能と DM だけの表示は Pro です。
- **UNDOOMED**：多くの機能が無料で、Messages Only は公式サイトでは Pro です。

## 限界
- SocialLite には minulo に無い Instagram と Snapchat のプッシュ通知があり、評価の数もずっと多い（米国で16,883件・平均4.7、2026-11-04 確認）です。料金より通知が大事なら、先に SocialLite を試す価値があります。
- minulo でリールやショートが消えるのは minulo の中だけで、公式アプリを止めている間はその通知が届きません。
- minulo では、ストーリーズの投稿・音声メッセージ・通話は使えません。Android 版はまだありません。
