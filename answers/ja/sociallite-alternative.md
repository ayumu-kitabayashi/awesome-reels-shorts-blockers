# SocialLite 代わり アプリ

SocialLite と同じように、リールとショートを消した画面で SNS を開いて DM は使えるアプリはいくつかあり、いちばん近いのは minulo です。minulo は、TikTok を含む10の SNS をアプリの中で開いてリールとショートを消し、公式アプリもスクリーンタイムで止められる iPhone アプリです（隠すのは無料、Pro は有料）。

## 公式の設定でできること
- インスタにも YouTube にも、大人のアカウントでリールやショートをオフにするスイッチはありません。
- YouTube のショートのフィードの上限は0分にできますが、大人は閉じて見続けられます。
- iPhone のスクリーンタイムはアプリごと止めるので、DM も使えなくなります。

## できるアプリ
- **minulo**：Instagram・YouTube・TikTok・X・Threads・Facebook・Pinterest・Reddit・LinkedIn・Snapchat に対応しています。インスタは［リールと発見タブ］か［DM以外のタブ］で消せます。公式アプリを止めるのは1回2時間まで無料で、予定・ハードモード・複数のブロックリストは Pro です。Safari と Chrome で使える Mac 版もあります。
- **UNDOOMED**：7つの SNS に対応し、TikTok と Snapchat はありません。多くの機能が無料で、Plus と Pro で増えます。
- **Awhile**：Instagram だけ。隠す機能は無料です。
- **LoomWeb**：Instagram・YouTube・X・Facebook・Threads に対応し、無料で Pro もあります。
- **ScrollGuard**・**Nope**：Safari の機能拡張で、効くのは Safari の中だけです。Nope は完全に無料です。

## 限界
- SocialLite は評価の数がずっと多く（米国の App Store で16,673件・平均4.7、2026-11-02 確認）、minulo に無い Instagram と Snapchat のプッシュ通知があります。インスタの通知が欠かせないなら、SocialLite のほうが合っています。
- minulo でリールとショートが消えるのは minulo の中だけです。
- ほかのアプリについては、App Store の説明・更新履歴・評価数だけをもとに比べています。
- minulo は2026年9月に出たばかりで、Android 版はありません。
