# インスタのアプリを消して Safari で使うと、DM とリールはどうなる？

DM は使えますが、instagram.com にもリールと発見があるので残り、インスタの通知も届かなくなります。minulo は、インスタのウェブ版を開いてリールと発見のタブとおすすめ投稿を消し、DM はそのまま使える iPhone アプリです（隠すのは無料、Pro は有料）。

## 公式の設定でできること
- アプリを消すと、アプリとそのデータが iPhone から消えます。アカウントと DM は残り、入れ直せば1分で元に戻ります。
- instagram.com をホーム画面に追加しても、同じウェブ版にアイコンが付くだけです。
- インスタの通知は公式アプリから届きます。DM の通知が要るなら、アプリは残して通知をメッセージだけにするほうが確実です。
- 大人のアカウントには、アプリでリールのタブを消す設定がありません。

## できるアプリ
- **minulo**：インスタのアプリは消さずに、minulo の中でインスタを開きます。歯車で［リールタブ］［発見タブ］［おすすめの投稿］をオンにし、DM だけにしたいなら［DM以外のタブ］をオンにします。どれも無料です。公式のインスタはスクリーンタイムで止められます（1回2時間まで無料）。
- **Nope**：Safari の instagram.com と youtube.com で、リール・ショート・発見・ストーリーズ・自動再生を隠す機能拡張です。無料で、アプリ内課金もありません。iOS 17 以降が要ります。
- **ScrollGuard**：Safari の機能拡張で、無料で Pro のアプリ内課金があります。1.2.1 で「DMs only mode」が加わりました。

## 限界
- 機能拡張が効くのは Safari の中だけで、minulo でリールが消えるのも minulo の中だけです。
- minulo では、ストーリーズの投稿・音声メッセージ・通話は使えません。
- minulo が公式アプリを止めている間は、そのアプリの通知は届かず、minulo が代わりに通知を送ることもありません。ただし 1.0.19 からは、Pro の方はベータ機能の DM の通知をオンにすると、Instagram を止めている間も Instagram の DM の通知だけは届きます（スリープモード・ワークモードの間と、1日の上限に達した後は届きません）。
- スマホのウェブ版で DM のどの機能が使えるかは、インスタのヘルプで確かめられませんでした。
- minulo の Android 版はありません。
