# インスタでフォロー中の人の投稿だけを見る方法は？

インスタでは、フィードの左上の［Instagram］から［フォロー中］を選ぶと、フォローしている人の投稿とリールが新しい順に並び、おすすめ投稿は出ません。この選択は残らないので、毎回その状態で開きたいなら、minulo の中でインスタを開き、歯車で［おすすめの投稿］［リールタブを非表示］［発見タブを非表示］をオンにします（消すのは無料、Pro は有料）。

## 手順
1. インスタを開き、フィード（ホーム）で左上の［Instagram］を押します。
2. ［フォロー中］を押します。30日前までさかのぼれます。開き直すとふつうのフィードに戻るので、そのたびに選び直します。
3. 見逃したくない人だけに絞るなら、同じメニューの［お気に入り］を使います。50人まで入れられ、追加しても外しても相手には通知されません。
4. 毎回選び直すのが面倒なら、minulo を入れて minulo の中でインスタを開き、ログインします。
5. Instagram の横の歯車で、［おすすめの投稿］［リールタブを非表示］［発見タブを非表示］をオンにします。次からも minulo で開くたびにこの状態です。DM と検索もふつうに使えます。

## ほかの選択肢
- **インスタの［興味なし］**：おすすめ投稿の［オプション］から選ぶと、ふつうのフィードのおすすめ投稿を30日間止められます。リールと発見には効きません。
- **Stillfeed**：アプリの中でインスタをフォロー中のフィードで開き、リールとショートを消します。
- **Reelmute・Awhile**：アプリの中でインスタを開き、リールを隠します。

## よくある質問
### ［フォロー中］にすれば、リールのタブと発見も消えますか？
消えません。変わるのはフィードだけで、リールのタブと発見タブにはフォローしていない人のおすすめが出続けます。また［フォロー中］の中でも、フォローしている人が載せたリールはフィードに出てきます。

### 公式のインスタアプリも、フォロー中から開くようになりますか？
なりません。minulo の設定が効くのは minulo の中で開いたインスタだけで、公式アプリから開けばふつうのフィードとリールのタブに戻ります。ストーリーズの投稿、ボイスメッセージ、通話はウェブ版に無いので minulo では使えません。minulo は iPhone と Android で使え、Mac 版もあります。
